02 / SAFETY CHECKLIST◈

Know what you are generating

01

Real, random keypairs
Uses the browser's Web Crypto Ed25519 implementation and Stellar's public/secret key encodings. Not a fabricated address without a signer.

02

No backend requests
The app has no network APIs. The production Content Security Policy blocks outgoing connections, external scripts, and framing.

03

Secret shown on demand
The result is held in page memory until discarded or the tab is closed. Copying puts it on your system clipboard, outside this site's control.

04

Offline is safer
For testing, self-host the static files on localhost. For anything valuable, disconnect after obtaining and inspecting the code, and use a trusted offline system.
